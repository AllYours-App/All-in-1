# Objectifs : Appli golf

Ce fichier est écrit par moi seul. Les comptes le lisent, ils ne le modifient jamais.

Résultat attendu :
Une appli qui regroupe tout pour s'entraîner au golf (GolfEvolution), pour tous les golfeurs, dans un but commercial. Publiée sur Google Play, puis sur l'App Store.

Périmètre de la version 1 :
- Tout ce que décrit le Guide fonctionnel du README : connexion, mode hors ligne, accueil, menu (profil, réglages, sac, distances, aide et support, données personnelles), Parcours, Putting, Wedging, Stats, Gym.
- À ajouter avant la mise en ligne : l'import de séances de sport faites ailleurs que dans l'appli.
- Langues : français, anglais, espagnol.
- Le README fait foi pour le détail des fonctions.

Après la version 1 :
- Module Vitesse.
- Séances proposées par l'appli.
- Autres domaines du jeu (driving, fers, bunker, mental...).
- Les personnalisations listées dans « Fonctionnalités à venir » du README.

Contraintes (budget, matériel, règles) :
- Je travaille seul.
- Gratuit aujourd'hui. Frais mensuels à prévoir (hébergement, comptes développeur des stores, éventuellement publicité). Budget maximum : non défini.
- Usage commercial : le statut « éditeur non professionnel » du README ne tient que si l'appli est gratuite, sans publicité ni abonnement. Dès qu'elle ne l'est plus : passage en statut professionnel (SIRET, adresse, médiateur, mentions légales et CGU), statut « trader » sur Google Play, et achats via l'achat intégré d'Apple pour les abonnements.
- Hébergement : vérifier que Cloudflare autorise l'usage commercial avant la mise en ligne.
- Règles des stores et RGPD (appli publique).
- App Store : Apple peut refuser une appli qui n'est qu'un site dans une enveloppe, risque à vérifier.

Échéance :
Le plus tôt possible. Pas de date fixée. Google Play d'abord, App Store ensuite.

Décisions que je dois prendre :
- Modèle économique : gratuit, publicité, abonnement ou achat. De lui dépend le passage en statut professionnel.
- Date cible de la version 1.
